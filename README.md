# Абизяна

Лендинг digital-команды на Next.js 16 и React 19.

## Локальный запуск

Требуется Node.js 20.9 или новее.

```bash
npm install
npm run dev -- -p 3001
```

Сайт будет доступен по адресу `http://localhost:3001`.

## Проверка перед деплоем

```bash
npm run check
```

Команда последовательно запускает ESLint и production-сборку Next.js.

## Production

Проект готов к размещению на платформе с поддержкой Next.js или обычного Node.js-сервера:

```bash
npm run build
npm run start
```

Секреты и переменные окружения сейчас не требуются. Если они появятся, храните их только в `.env.local` или в настройках хостинга — файлы `.env*` исключены из репозитория.
